# Karabiner Elements Customization

## Install custom keybindings

Install the keybindinds as follows:
1. Place `joshtreepark_custom.json` into `FOLDER NAME` (TODO: look up later)
2. Or copy and paste a section of the json starting from `description`.

Currently only using `"fn+# will set input_source (change keyboard language)"` and `"Change caps_lock to esc/command"`

## Online Download

Download the following from the `Complex Modifications > Add Predefined Rule > Import more rules...`

Title: Press Left Shift and Right Shift to toggle Caps Lock 
Last Accessed: 2026-03-30
[Left Shift + Right Shift Link](https://ke-complex-modifications.pqrs.org/?q=shift%20to%20capslock#press_left_shift_and_right_shift_together_to_toggle_caps_lock)
